种⼿法。
⼀、Mr.Bill 如何做出那种「渐快、渐慢」的声响效果。
https://www.youtube.com/watch?v=hbsQ3w0hPcw
总结为：选择⼀声 Decay ⽐较⻓的 Kick 采样、点击采样、点亮 Warp，模式
选择 Texture，BPM 推⾼到 999，Flux 设为 0 或 100，然后⼿动调整下⾯的
Grain Size。如果你操作后发现那种抽拉效果不明显，可尝试提⾼ Pitch。最后
去下⽅的 Envelopes 栏⾥选择 Grain Size 进⾏ Automation 的画线。（需要注
意，那种渐慢的抽拉的效果需要反复尝试 Grain Size 的数值，找到 Sweet 
Point。）
这⾥的逻辑是（这⼀段如果看不懂也没关系）：
1、设定采样的原始 BPM。代表着「告诉 Ableton 这段采样原本的 BPM 是多
少」，现在我们告诉 Ableton 它的原始速度的 999，⽆⽐快，⽽我们此刻做歌
的 120 BPM 下，为了 Warp 住现在的 BPM，原始采样就需要极⼤减慢速度，
这也就拉⻓了采样。
2、Texture 模式。纹理模式，代表着「更在意声⾳的每⼀个瞬间（粒⼦）⾳⾊
的算法」，要做出那种渐慢的抽拉效果，这种模式最适合。Grain Size 就是每
⼀个瞬间的粒⼦⼤⼩，粒⼦越⼤，在⼀秒内「连起来发声的密集 Audio」就越
少，所以⼩粒⼦们连起来的声⾳，⾳⾼更低；粒⼦越⼩，在⼀秒内「连起来发
声的密集 Audio」就越多，所以⼩粒⼦们连起来的声⾳，⾳⾼更⾼。Flux 就是
Fluctuation，波动性，这⾥波动的是粒⼦⼤⼩，相当于添加了⼀个随机效果，
开到最⼤时，每次做出的声⾳都会有轻微不同。
注意：从 Ableton Live 12.2 之后，Warp ⾥的 Tone 算法进⾏了升级，⾮常适
合⽤来做 Glitch 的采样。如果 Texture 模式出来的效果不满意，可以切到
Tone 算法试⼀试，它的逻辑与 Texture 类似，只需要变化 Grain Size 即可。
Mr.Bill 后续的做法其实过于复杂了，因为他最终只是为了⽣成⼀段 MIDI 
Clip，⽅便之后可以把这种「抽拉渐慢」效果适⽤于任何⾳⾊。⽽我们只需要
先在 1/16 或 1/32 的 Grid 下写⼀堆逐渐稀少的⾳符，然后右键把「Snap to 
Grid」取消掉，此时就可以⼿动⾃由移动⾳符位置，⼏秒钟就可以完成你想要
的任何稀疏度的 MIDI ⾳符。然后把这个 MIDI Clip 重命名为 Make Some 
Slowing Down EFX，存下来，以后任何时候想⽤，挂上不同的⾳⾊就可以。
事实上他分享的这个招数⾥，我更喜欢的⽤法是：先把这个 Kick 继续
CMD+D ⾮常⾮常多遍，然后 CMD + J 合成⼀个⻓采样，点亮 Warp 选择
Texture 模式，BPM 再次设为 999。此时就是⼀个⽆⽐⻓的 Audio，开录⾳，
在录⾳过程中⽤⿏标疯狂移动 Pitch 和 Grain Size，录出⾮常多乱七⼋糟的效
果，总能切出⼏份⾃⼰想要的 Glitch ⾳⾊。
这⼀招使⽤不同的采样，录出来的效果会⾮常不同。⽐如你还可以尝试扔进去
⼀个已经成型的 Beat。
注意：当切出来了很多想存的 Audio Fills，在存之前，务必对它们单独进⾏
CMD+J，让它变成⼀段确切的⼩录⾳再存。如果直接存，那么存下的是整条
Clip 的全部声⾳。⼀个⽅便的检测⽅法是，看存下来的 Audio 后⾯有没有时间
戳，时间戳是 CMD+J 后的产物。
这是我看这类技术分享时强迫⾃⼰的习惯，也希望⼤家可以⽤起来——如果我
看了别⼈的⼀个分享，学到了有⽤的技术，则我必须同时做两件事：1、这个
技术的流程我能否优化？2、这个技术我如何再进⼀步做出⼀种新的选项出
来？因为任何⼀个技术分享视频，全世界都会有⼏百到⼏万个制作⼈看到，假
设其中⼗分之⼀的⼈真的学会、应⽤了，那就会有⼏⼗到⼏千⾸歌会⽤到这⼀
招，如果不做到更进⼀步，⾃⼰的⾳乐就⽆法独⼀⽆⼆。
如果⼤家也能养成这样的习惯，⻓久坚持下去，你的⾳乐就会充满「标识
性」，别⼈⼀听就会知道这是你的⾳乐。从装屄的⻆度讲，只有你这么做了，
才能在未来⾃称「⾳乐制作技术冠绝全球」时更有底⽓。
⼆、Mr.Bill 如何做出⻉斯⾳⾊。
Dubstep 的那种嘶吼⻉斯通常是⽤ Serum 这个合成器做出来，但我们没必要
买，因为完全可以使⽤ FM 合成器 + ⼀堆效果器组合做出来。
1、Operator 默认的 FM 合成器，写⼀个 C2 的⾳。
2、Osc A 的 Level 保持不动，尝试把 Osc BCD 的 Level 全都推⾼到 -20 左右，
Coarse 都设为 0.5。Spread 推到最⾼，此时得到⼀个低沉但很宽的 Bass 声
⾳。
3、加⼊ Auto Pan，Phase 推到最低的 0 度，此时 Autopan 就变成了⼀个针
对⾳量的 LFO，Rate 根据你的喜好选择 1/8 或 1/12。
4、Saturator 的 Drive 推到最⾼，让 Bass 失真。此时已经开始有嘶吼质感。
5、最后加⼊ OTT 的默认预置，它会让原本更响的低频⾳量降低、让原本更⼩
的⾼频⾳量提⾼，于是嘶吼更清楚、低频不会那么重。
6、之后，根据⾃⼰的喜好：加⼊ EQ 提⾼或降低某些频率、加⼊⼩数值的
Overdrive 让嘶吼更粗粝（30% 左右）、调整 FM 合成器⾥的 Osc BCD 看能
不能得到⼀些更不⼀样的嘶吼⾳⾊（通常调整离载波最近的 Osc B 效果最明
显，提⾼它的 Level 可以让低频显得更猛。提⾼它的 Amp Env 的 Sustain 可以
让中⾼频显得更燥）。
7、把这个⾳⾊命名为 Growl Bass for Dubstep，存下来。
三、Mr.Bill 如何安排 Fills。
https://www.youtube.com/watch?v=8NLMQwzETl8
这个视频⾥他⽤了上⼀招同样的⼿法，只是采样不再是⼀个底⿎⾳⾊，⽽是回
录了⼀遍歌曲⾥的⽚段，再点亮 Warp、采样原始 BPM 推到 999，此时这段⾳
频就被⽆限拉⻓（但⾳⾼还是对的，原汤化原⻝）。然后再开⼀个录⾳轨道，
开始反复拖拽 Grain Size，录出⼀堆⾳效（此时就不能拖拽 Pitch 了，因为这
⾥的 Fills 要在调式内）。如此录出⼀⻓串 Fills 后，把它们放在段落连接处，
Mute 掉上⼀段落的⼀些轨道，加⼊这些 Fills 做连接。
3 分 52 秒处，这⾥他⽤了⼀个 Hack 的不优雅⼿段解决了 Ableton 带来的⼀个
「问题」。他想要的是「固定住采样的⻓度，然后通过移动采样的 Start 位置
来选取不同的段落」，但 Ableton 总是会改变采样的⻓度。所以它找了⼀个空
Audio Clip 放到后⾯，前⾯的采样就被固定住了。其实这个「问题」更好的解
决⽅案是，点亮 Audio Clip ⾥的 Warp，然后点亮 Loop，⼀个采样⼀旦被
Loop 了，它的⻓度就被固定了，瞬间解决（在 Ableton Live 12.1 之后，你甚
⾄不需要点亮 Warp 和 Loop，直接对着 Clip ⽤快捷键 Option + Shift + ⿏标
左键左右拖拽也可以实现）。
如此我们⼜为他的流程做出了优化。接下来我们如何做出⼀种新的可能性呢？
把他的操作更进⼀步，例如有⼀段录出来的效果⾮常满意，但节奏与歌曲搭不
上。这在 Resampling ⿎组时最常⻅，其他⾳⾊如果有节奏搭不上问题并不
⼤，因为只要⿎组能搭上那么听感上⿎组就校准了节奏。所以如果⿎组类⽚段
节奏搭不上，此时我们选择的⽅法是，提升下⽅的 BPM，最好能到 400 以
上，显然不是正常歌曲的速度，这样采样就被充分拉伸了，再让所有瞬时性⼤
的⾳头都恰好落在 Ableton 的 1/16 或 1/8 Grid 上，这样节奏就贴合了，然后
再切换 Warp 的模式，找到⼀个你觉得⾜够刺激的声⾳。
这节课我们来学习 Mr.Bill 创作手法中最重要的一环，Idea Jam。非常适合没灵
感时进行的「随便弄点什么声音出来」的创作方式。
在 Idea Jam 之前，需要做一些准备工作，先制作一个简单的鼓组 + 简单的
Bass Arp 作为 Idea Jam 的铺底用，这两轨在最终的成品里并不一定会用到。
BPM 128-140。越快越好，更快的速度下，Fills 的连续闪现会更有「应接不
暇」的特征，更容易让人听不过来从而不明觉厉。此外，Dubstep 恰好就是
140 的速度（其实原始的 Dubstep 速度是 70），非常适合 Mr.Bill 曲风。
一、鼓组
可以使用 BandLab Glitch Hop 这个采样包里的鼓组音色，做类似 Glitch Hop 
风格的鼓组，这个采样包的音色质量不错，但都是长采样，因此需要使用
Sampler 切出来；也可以使用 Ableton 的 Drums 里那些此前没用过的千奇百
怪的鼓组音色，制作其他听感的音乐（Dubstep 的鼓组特征我们下节课讲）。
Mr.Bill 曲风的作业，大家制作出来的成品听感上一定会差异极大。
如果选择做 Glitch Hop 这种曲风，则记得所有轨道都加入相同数值的 Swing，
只要一种曲风里有 Hop 字样，必有 Swing。
如果选择自建的鼓组，则点进 Kick 音色，给一点 Pitch Envelope（通常
+12st 即可，然后调整 ADSR 的 Decay），Mr.Bill 几乎所有底鼓的音头都会有
非常明显的 Pitch Envelope 痕迹，让 Kick 显得特别的突出，突出原因就是
Pitch Envelope 的起始频率高到了中频范围，能被人耳更明显的识别到。
二、Bass Arp
Bass 音色的设计方法步骤：
1、Wavetable，Osc 1 和 2 都选锯齿波，其中一个推高 Detune，以便后续产
生一些立体声；
2、Frequency 高切到 200Hz 左右，提升 Reso 到 60-80。
3、Frequency Env 轻微推高。
4、Unison 选 Phase Sync 或 Position Spread。两种听感都是经常在 Mr.Bill 
和 Deadmau5 的音乐里听到的（因为这四步其实就是在重现 Serum 的合成器
设计操作过程）。这里需要注意，Phase Sync 和 Position Spread 对应的
Freq Env 推高的数值会不太一样，Phase Sync 推高一点点 Env 就够了（20 
以内），Position Spread 则需要推比较高（40 以上）才能有 Deadmau5 的那
种类似 303 的 Arp 听感。可以根据自己的听觉喜好来定数值。
注意：
1 里提及的「推高 Detune 即可产生立体声」是一个不精确的说法。我们熟知
的两种可以产生立体声的行为，Phase 和 Spin，Detune 属于 Spin，也就是起
始位置完全一致，此后逐渐开始分出快慢导致不一致。Phase 是一定会直接导
致立体声增加的，因为它本身就把声音分为左右声道；而 Spin，也就是这里
的 Detune，如果在 Mono 状态下，只会由于相位抵消而产生「声音时大时
小」的颤音效果，而不会直接产生立体声。Wavetable 默认的 Unison 是
None，其实就是 Mono，所以增加 Detune 这一步并不会立刻产生立体声，只
有在 Unison 选择了各种选项后（也就是分成了左右声道后），Detune 的增加
才能增加立体声的宽度。这其中有先后顺序。
然后是 Arp 的做法：
Mr.Bill 的 Arp 基本是用 Serum 这款合成器里附带的 Arp 来实现的，听感会比
Ableton 的 Arp 多一些可能，但听久了依然很枯燥，所以我们有三种方法来写
Arp：
1、使用 Ableton 的 Arp，琶单音，永远不会出错。可以试试 1/12 的 Rate。
2、使用 Ableton 的 Arp，写和弦，录下 MIDI Notes，然后手动去更改其中的
一些音符。（在四小节的结尾处，可以尝试 1/16 Triplets 的四个音符，这是
Future Bass 和 Glitch 类音乐非常喜欢的招儿。）
3、使用随机性更强的 MDD SNAKE。选好 Scale，然后把 Notes 里的范围选
择，靠下一些，让 Random 出的音符大概在 1-2 字头。之后就不停点击
Random All，试出一个自己效果满意的 Arp 段落；另外，如果 Bass 的音高很
高，则 Arp 的音符数要少，相当于 Arp 也作为 Fills 存在，可以手动把 Gate 里
的触发位置多数点灭；如果 Bass 的音高很低，则 Arp 的音符数可以多，相当
于铺底的作用，可以手动把 Gate 里的触发位置多数点亮。得出一段满意的音
符后，开空轨道，把刚刚的 MIDI 信息录下来，然后根据和弦进程，把他们的
位置以一小节或两小节为单位进行手动位移。
注意：MDD SNAKE 最新的 3.2.3 版本我发现了两个偶尔会发生的 Bug：1、
它的 Scale 有时会失效（所以保险起见，我们依旧需要在 MDD 之后添加
Scale 里的预制）；2、通常我们使用 MDD SNAKE 时不需要输入任何音符，
它会自己选音符来琶音，但如果轨道里已经有和弦的 MIDI Notes，它有时候会
根据你更换和弦的时机去全随机变一次（但有时候是一个和弦一换，有时候是
两个和弦一换，具体机制不明），因此我建议还是使用空轨道然后录下来。
三、Idea Jam
首先我们看这个视频：
https://www.youtube.com/watch?v=-luqhrqUwhA
从 4 分钟到到 16 分钟，我们可以看到 Mr.Bill 如何让一个简单的 Operator 正
弦波变得「糙」。之后他对着这个音色反复的按键并录下来，这个过程就是他
的 Idea Jam。
我一直在使用的 Idea Jam 手法与之类似，但与 Mr.Bill 稍有不同。过程是：
1、只录 MIDI。我在 Idea Jam 阶段不会录制 Audio，只录 MIDI，因为我们手
弹出来的东西大概率节奏非常不稳，这样录出来的 Audio 是没啥使用价值（或
者需要进行大量的 Warp 打点操作才能用，非常浪费时间）。而只录 MIDI 的
话，录完后全选音符，右键，Quantize 量化，就能把节奏调整到稳定状态，方
便接下来使用。在录 MIDI 时，还可以开一个 Scale，这样就算你在乱弹，录出
来的 MIDI 也会在调式内。只有一种情况我会同时录 MIDI + Audio，就是弹
MIDI 键盘的那个人是个顶级乐手，他们录出来的东西不仅不需要太多量化，力
度控制还特别好（顶级乐手和乐手最大的区别就是对力度控制的理解），这样
录出来的 MIDI 换啥音色听起来都对。
2、多出来的步骤是：把 Quantize 后的稳定 MIDI 轨道复制出很多轨，第一轨
加入原本的音色，Freeze + Flattern 成 Audio。之后每一轨都加入随便一个什
么音色，看能不能触发一些自己意想不到的效果，如果效果喜人，则这一轨才
Freeze + Flattern 成 Audio。
3、当我们最终得到了一些满意的 Audio 轨道，再针对它们进行疯狂切片，切
出自己想要的声音（这个过程此前需要持续数天，每天 2-4 小时，但现在随着
Ableton Live 11 的新功能出现，简单多了，我们会在第 140 课时具体学
习）。然后把最终切出来的所有 Fills，全部视为鼓点，去构成一个节奏。
这个视频里另外一个值得学习的招数是 1 小时 08 分开始的「Sampler 自动选
择位置」的手法，它的应用场景是「非常长的采样」，例如我们上节课拉伸出
来的那些长采样。
我们可以把这节课写完的鼓组 + Bass Arp 当做基底素材，把它们 Resamping 
出 4 小节，然后 Warp - Texture - Grain Size 乱调，得出一个 4 小节的长采
样。
接下来的步骤是：
1、把长采样放进 Sampler 里。
2、选择最右的 MIDI 界面。Velocity，关联 Sample Offset，Amount 推到
100。此时音符的力度，将决定采样的播放位置。
3、写一堆一模一样的音符。（这里按照我们的优化习惯，只需要写一个长音
符，然后上 Arp 效果器。这样不仅省力，接下来还有新的用法。Mr.Bill 在视频
后面也用了 Arp。）
4、上 Velocity 效果器，推高 Random。生成的力度几乎涵盖 1-127 的所有力
度，如此就用随机力度确定了随机开始位置，解决了 Sampler 的 Sample 
Start 不能 Automation 的问题。如果想彻底涵盖所有力度，把 Out Hi 和 Out 
Low 都设为 63，Random 推到最大，就可以实现全力度覆盖。
以及我们的更进一步优化用法：
5、把 Arp 的 Rate 调整到 1/64 或 1/32，然后把 Gate 拉低，通常可以得出非
常 Glitch 的音色。再进一步，上一个 LFO，作用于 Rate；再上一个 LFO，作
用于 Gate。如此可以得到更多的可能性。
最后还可以再开录音，再把整串效果录下来，再找其中满意的部分，放置到自
己满意的位置……
效果器的组合是无止境的，做出来的效果录下来也总有得可用，你永远可以在
自己看到的技术分享里再进一步，长期坚持下去，最终让自己的音乐独一无
二。因为这样做出来的声音他人无法复制，而你又可以长期复用。
Mr.Bill 提出过这样一个理念，至今被我奉行，未来也会是 HEMe 所有制作人的
一个准则：「一首歌至少 40 小时有效工作时长」。这里的 40 个小时是有效工
作时长，不包含那些用于思考的时间。
考虑到 Mr.Bill 制作一首歌的主体部分通常只需两三个小时，除了 Drums + 
Bass Arp，还固定会出现的只有 Sub 和 Chords（Chords 通常有两种身份：
或者作为氛围 Pad 出现，或者作为 Fills 出现）。
所以此时我们可以选择的曲风有三种支线：
1、Glitch：
这是现阶段 Mr.Bill 最主要的曲风之一。如果选择该曲风，速度需要调整回
130 以下。且需要大量 Fills。（额外注意：如果是 Glitch Hop，则需要加入
Swing。）
2、Dubstep：
这是现阶段 Mr.Bill 最主要的曲风之二。如果选择该曲风，鼓组需要变成：让重
音 Kick 出现在第一拍且 Snare 只出现在第三拍，Dubstep 的鼓组是少且重
的，空隙的部分则用各种 Bass、Chords、Fills 填满。
3、Drum&Bass：
这是 Mr.Bill 早期制作的曲风。如果选择该曲风，鼓组改为 Amen Brother 鼓
组。
-
由于 Mr.Bill 的 Bass Arp 时常会跨两个甚至三个八度，相当于把 Lead 的工作
也给做了，所以他的歌曲主体通常就只有：
Drums
Bass Arp / Lead
Chords
Sub
几个小时就可以完成这些，之后剩下的 30 多个小时他会一直进行 Idea Jam，
制作出无尽的 Fills，最终把一首简单寡淡的歌变成丰富多彩的歌。我们会在下
节课用更快的手法制作出其余的 Fills 来继续填充工程。
在学会了一些声音设计手法后，我们对效果器的认知会增强，也会很容易沉迷
在声音设计里。但是用 Idea Jam 手法制作出的歌曲，我却并不会很想发出来
——在经历了一年多疯狂的声音设计之后，我发现我制作出的此类歌曲并不具
备比 Mr.Bill 更复杂或更进一步的听感，它们听起来仅仅是 Mr.Bill 的习作，完
全不具备我自己的风格。
于是我开始解决这个问题，尝试做减法。这是做减法最好的时机：
https://www.youtube.com/watch?v=-jLi6ZdVzfc 
先知道什么是「多」，且能做到「多」，然后才可以开始「少」。因为那会儿
的少，会少的更有理有据、有主动有智慧的去选择减掉哪些部分，最终达成的
不是「少」，而是「好且少」。
而在音乐领域，这个「好且少」，最后一定会落在 Pattern 上。Mr.Bill 的歌曲
普遍缺少好的 Pattern，偶尔就算一些 Fills 构成 Pattern 了，他会在下一段略
过去换成新的 Fills，这也是最终导致他的歌曲缺乏记忆点的原因。而一旦你有
了好的 Pattern，很自然会为了突出 Pattern 去减少一路上所有会造成「听觉拥
堵」的 Fills，这些 Fills 就回归到了「增加细节」的原始定位上去。而当你没有
好的 Pattern，会发现哪个 Fills 都不舍得删、不应该删，删掉任何一个似乎都
觉得那里很空。
大家此刻还没有度过那个漫长的声音设计的学习过程，所以做减法这事儿并不
需要立即去做。为了帮助大家尽快渡过这个阶段，把一年多缩短为几个月，在
沉迷声音设计的时间内，以下是我的两个最大心得：
1、通读 Ableton Live 的官方说明书。一页不落的看完、每页都进行实操的看
完。因为我发现 Mr.Bill 在分享教学视频时，总会大段引述说明书内容，所以找
到了症结所在——人家之所以有那么多招儿，是因为把说明书全看了一遍，于
是每一个别人不用的、一眼略过去的冷门功能都可以变成声音设计的一环，所
以我花了接近一年时间去通读 Ableton Live 说明书。好消息是，现在说明书已
经有中文版了，大家的整个阅读过程会比我当初轻松太多，每天八到十页，两
三个月即可完成。
2、除非你从事的职业是音效工程师，否则声音设计永远不会是音乐的主体，
它只是音乐的载体。我们需要时刻记得，Pattern 才是 99% 的听众会聆听、会
记忆、会哼唱的东西，甚至它们是唯一会被听众「感受」的东西，那些复杂的
Fills，只会粗略感受为「厉害」，然后就没有了，这些 Fills 无法给听众更多的
深入感受、联想的东西。终其一生将全部精力放在只有 1% 听众在意的音乐人
当然是值得尊敬的，但他们的音乐不会为人所知我们也必须接受，这是现阶段
文明的人类听觉习惯所决定的。
所以，写 Pattern。写 Lead Pattern。
⼀、Chop
Chop 即「切⽚」，是 Glitch 类⾳乐最耗时的部分，但在 Ableton Live 11 更新
了⼀个名为 Take Lane 的新功能后，效率获得了⼏⼗倍的提升，以前数⼩时的
Chopping ⼯作量现在⼏分钟就可以完成。
Take Lane 这个功能的设计初衷是 Ableton 为了⽅便乐⼿和歌⼿录⾳。当乐⼿
或歌⼿录⾳时，每⼀遍总会有特别出彩的部分，也会有或⼤或⼩的失误，所以
每次录⾳都会同⼀个轨道反复录很多遍，然后选择其中最好的部分来切着⽤
（未来⼤家⾃⼰录⾳时，务必也要录多遍），于是就有了所谓的 Take 1、
Take 2、Take 3（第⼀条、第⼆条、第三条）……⽽ Take Lane 这个功能可以
在 Loop 状态下⽆限录⾳，刚刚录的所有⾳频都会逐条呈现在「下属轨道」
⾥，这样我们可以在 Lane 轨道⾥选择每⼀遍⾃⼰喜欢的那⼀部分，仅需要按
⼀下回⻋，选中的部分就会出现在上⽅的 Audio 轨道上。如果你⾃⼰录⼈声、
吉他、键盘、⻉斯，这个功能会⽆⽐省事。
在看到这个功能后的第⼀时间，我发现在轨道上右键，有 Insert Take Lane 的
单独选项，所以很快就想到了解放⽣产⼒的 Chopping 新⽅法。（它的快捷键
是 Option + Shift + T。如果找不到这个选项，说明你正处在 Automation 模式
⾥，⽆法进⼊ Take Lane 模式，把 Ableton 上⽅的 Automation 模式关掉即可
进⼊）：
选择⼀个空 Audio 轨道，先右键勾选 Show Take Lanes，然后右键 Insert 
Take Lanes，就新建出了第⼀个 Lane；之后选中第⼀个 Lane，⽆限
CMD+D，就能新建出⼀堆 Lane；然后把想要 Chop 的所有⾳频逐个扔进去，
然后只需要⿏标框选⾃⼰想要的部分，按⼀下回⻋，⼀段充满「断续感」的
Chop 采样就完成了。
（相信我，这么简单点事⼉，以前需要数⼩时。最开始是新建⼀堆轨道，然后
⼀个⼀个切⽚、⼀个⼀个⽤⿏标拖拽，⼀个⼀个把采样互换位置，⽆⽐考验⼈
的⿏标灵敏度和耐⼼。后来看了 Mr.Bill 的⽅法，他会新建⼀个 Group，把⼀堆
采样⻬头放进去，然后选择⾃⼰想要的部分，切出来，不想要的部分，按 0 给
Mute 掉，时间节省了⼀些，但不需要的部分远⼤于需要的部分，所以就是不
停的按 0，每⼀次想尝试新的可能，重新听⼀遍，重新切、重新按 0……）
除了「扔进去⼀堆采样」的⽅法，之前课上提到的 Texture 模式录⾳也可以通
过 Lane 的⽅式解决：点亮 Loop，只管在 4 ⼩节或 8 ⼩节⾥循环着录，录完
之后对着该轨道 Show Take Lane，此前录的每⼀遍就都记录下来了，选取⾃
⼰想要的回⻋即可拼出⼀段采样。
总之，你可以在 Lane ⾥扔⼀切，然后快速 Chop 起来。
⼀个⼩技巧：Take Lane 时，可以把每四⼩节的最后⼀个采样，固定放置⼀个
通⿎类的短 Fills，有⼀种「过⻔⼉」的感觉，这是 Mr.Bill ⾮常常⽤的套路。
⼆、Automation
⼀旦你完成了 Chop，接下来⼀个必须要做的⼀件事是效果器参数的疯狂
Automation。⻅这个视频，他给⼀轨 Bass 添加了多少效果器的 Automation：
https://www.youtube.com/watch?v=-wA8GDNFm7A
Mr.Bill 听感的千变万化不仅因为⾜够多的 Fills，还因为任何⼀个可能引起⾳⾊
改变的参数，他都有耐⼼去做 Automation。
在做 Automation 时，可以有两种思路：
1、针对某个参数，进⾏超⻓时间内的渐变，⽐如在 16 ⼩节内某个⾳⾊的⾼切
逐渐放开。
2、针对某个参数，⼀直不动它，只在某⼀⼩节甚⾄半⼩节内让它忽然有⼤范
围的 Automation。这样做往往能试出⼀些⾮常抓⼈的效果，是 Mr.Bill 最爱⽤
的 Automation ⽅式。
三、「短」
短之于 Mr.Bill，其实是⼀个⽤编曲⼿法解决混⾳问题的思路：
如果 Idea Jam 是 Mr.Bill 编曲⾥最重要的⼀环，那么「短」就是 Mr.Bill 混⾳⾥
最重要的⼀环。他的歌曲⾥元素⾮常多，只有每个元素都很短，才能让下⼀个
元素能明确。「短」也是他的歌曲听起来「⾳⾊⽆⽐清楚」的关键所在——如
果⼀个轨道⾥的⾳⾊前后始终相连，那么它很容易淹没在整⾸歌的所有轨道
⾥，但如果这个轨道时断时续，你的⽿朵反⽽会去抓取这些细节，所以务必保
证 Fills 轨道是短的。
事实上，Mr.Bill 除了作为氛围的 Pad 以外，其他所有⾳⾊都很短促，这是「清
楚」的最⼤原因。所以哪怕是你的 Bass Arp 轨道，Gate 也要短，任何「连成
串」的⾳⾊都⽆法「清楚」。
注意：1、即便是 Pad，我们也应该把它 Bounce 成 Audio，当某个段落存在
Fills，就对着 Pad 疯狂按 0，让 Pad 也短促。不要不敢下⼿，「被 mute 掉的
部分⽐发声的部分多」才是 Mr.Bill 按 0 的常态。
2、Drum Racks ⾥的每⼀个发声的⿎组，都点进这个具体⾳⾊，把它的尾巴缩
短。
另⼀个「⾳⾊⽆⽐清楚」的关键，是除了 Kick、Sub 和 Bass 之外的所有轨道，
Mr.Bill 都会在 Stereo 模式下强制低切 130Hz。因此低频和低频以外的部分就
呈现得⾮常分明。但我个⼈不太推荐这种处理⽅式，它会让 80-130Hz 这个频
段显得⼲瘪，这在⽿机听起来并⽆问题，但以⼤功率⾳响播放出来的效果，虽
然⼲净但总是缺少⼀点低频的⼒量。
